{{range .JS}} {{end}} {{/* jobStageBadge renders a job's progress as one badge. Takes a domain.JobProgress. It used to show two values, generated / keyframes, from the Generated boolean alone, so "not a single one rendered yet" and "one video left" looked the same. Showing the stage and a fraction makes the remaining work and how far the billing has gone readable from the listing. */}} {{define "jobStageBadge"}} {{if eq .Stage "completed"}} {{.Label}} {{else if eq .Stage "videos"}} {{.Label}} {{else if eq .Stage "keyframes_done"}} {{.Label}} {{else if eq .Stage "keyframes"}} {{.Label}} {{else if .Stage}} {{.Label}} {{end}} {{end}} {{/* The badge for the job's own state. The stage (jobStageBadge) is how far the cuts have been rendered; this is whether processing is alive. A failed job only stops partway through its stages, so without this it cannot be told from a job in progress. For succeeded jobs the stage badge tells the result, so nothing is shown. The argument is a VideoHistory. */}} {{define "jobStateBadge"}} {{if eq .State "failed"}} failed {{else if eq .State "running"}} running {{else if eq .State "queued"}} queued {{end}} {{end}}
